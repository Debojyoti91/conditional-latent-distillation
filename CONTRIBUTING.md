# Contributing

Reproducibility reports and documentation fixes are welcome. Open an issue describing the scientific task, exact command, Python/dependency versions, and minimum reproducer.

For any numerical result change, identify the original manuscript figure/table, cohort version, preprocessing, random seeds, and whether the result is cached or newly trained. Never silently replace reported manuscript results with a new stochastic run.

**Do not commit pretrained or trained checkpoints, saved scalers, credentials, private information, or unapproved third-party data.** Review the staged files before each push.
