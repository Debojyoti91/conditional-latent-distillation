# Conditional latent distillation

Manuscript-linked code and reported analyses for *Conditional latent distillation decouples representation, search and chemical realization in sparse-data materials design*.

**Publication status: the complete code and data package has not yet been pushed to this repository.** The prepared, checkpoint-free release contains analysis workflows, tests, selected artifacts, figures, and provenance records; the large polymer CSV is configured for Git LFS.

A public release needs the full package pushed and GitHub Actions verified. Trained checkpoint files and fitted scalers are intentionally excluded. Historical surrogate model states and some MD inputs remain unavailable, so cached-result replication is not equivalent to comprehensive retraining.

The final coauthor and licensing approvals remain pending. No MIT or other source/data license is assigned without authorization.
